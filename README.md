# Coventry City FC — Identity Renewal Proposal

An independent English-language landing page presenting a Coventry City FC brand identity renewal concept by Park Jaeyoung.

## Core idea

Preserve Coventry's symbolic heritage while simplifying the crest into a clearer, scalable system for a new Premier League era.

The proposal retains the symbolic language of the elephant, three towers, eagle, phoenix, flame and football, while reorganising them into a contemporary circular badge structure. The visual system prioritises Sky Blue, deep navy, white and a controlled red accent.

## Landing page structure

1. The Moment — Premier League return and why now
2. Why Propose Change? — clarity vs. complexity
3. Keep the Memory — heritage symbols
4. Crest Architecture — proposed hierarchy
5. Design Principles — recognisable, scalable, flexible, Coventry
6. Visual System — colour and reproduction modes
7. Applications — kit, digital, stadium, supporters, broadcast, retail
8. A Note from Seoul — personal P.S. from the designer
